# 3 hướng giao diện trang chủ TomCaShop

Mở file `.html` bằng trình duyệt (cần mạng để tải font + Tailwind). Ảnh chụp ở `anh/` (390px điện thoại, 1280px máy tính).
Sản phẩm, giá `xxx.000đ`, hình vẽ vali/cặp và Cá Baby chỉ là **minh họa** — web thật lấy từ products.csv và ảnh chụp thật.

| | A · Biển xanh dịu | B · Kẹo ngọt | C · Tối giản tinh tế |
| --- | --- | --- | --- |
| File | `mau-a-bien-xanh.html` | `mau-b-keo-ngot.html` | `mau-c-toi-gian.html` |
| Cảm giác | Mềm mại, tươi sáng, thân thiện | Vui nhộn, nổi bật, viền đậm kiểu sticker | Sang, thoáng, tập trung vào ảnh sản phẩm |
| Xanh / Hồng | `#2B8FD6` / `#E85A8B` | `#1E6FE0` / `#FF4F8B` (+ vàng `#FFD34E`) | `#24467E` (xanh navy) / `#E8A6BC` (hồng phấn) |
| Nền | Trắng + xanh nhạt, đường sóng | Màu kem, chấm bi | Trắng + màu cát |
| Cá Baby | Nổi bật, bơi nhẹ ở banner | Nhãn dán "chào bố mẹ" | Nhỏ, tinh tế |
| Hợp khi | Ảnh sản phẩm nhiều màu, muốn an toàn, dễ đọc | Muốn khác biệt trên Facebook/TikTok, khách trẻ | Ảnh chụp đẹp, đồng đều; định vị giá cao hơn |
| Lưu ý | Dễ giống nhiều shop khác | Cần ảnh nền sạch để không rối | Kém "trẻ em" hơn; cần ảnh thật chất lượng |

Có thể ghép: ví dụ bố cục A + màu C, hoặc nút/thẻ kiểu B trên nền A.
